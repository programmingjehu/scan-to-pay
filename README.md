# Boque confession page

This is a static HTML/CSS/JS page designed for a romantic invite.

## Files
- `index.html` - landing page
- `invite.html` - main confession page
- `style.css` - styling
- `qr.html` - QR preview page

## GitHub Pages
This project is ready to be deployed as a static site on GitHub Pages.

1. Push this folder to a GitHub repository.
2. In the repository, open Settings > Pages.
3. Set source to "GitHub Actions".
4. The workflow in `.github/workflows/deploy-pages.yml` will publish it automatically.

## Public URL example
After deployment, your site will look like:
https://username.github.io/repository-name/
